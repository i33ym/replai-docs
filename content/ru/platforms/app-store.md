## Обзор

Подключите свой аккаунт App Store Connect к Replai — автоматически синхронизируйте отзывы о приложении, отвечайте на отзывы пользователей с помощью ИИ и управляйте всем из единой панели.

---

## Требования

Перед подключением убедитесь, что у вас есть:

- Членство в **Apple Developer Program** (платное, $99/год)
- Доступ к [App Store Connect](https://appstoreconnect.apple.com)
- Ваше приложение должно быть **опубликовано** в App Store
- Роль **Admin** или **Account Holder**

---

## 1. Вход в Apple Developer

### Шаг 1: Войдите в систему

Перейдите на [appstoreconnect.apple.com](https://appstoreconnect.apple.com) в браузере. Введите данные Apple ID в поля **Email or Phone Number** и **Password**, затем нажмите **Sign In**.

<img src="/images/app-store/01-sign-in-apple-developer-account.png" alt="Вход в Apple Developer" style="max-width:100%;border-radius:8px;" />

### Шаг 2: Двухфакторная аутентификация

На ваше устройство Apple будет отправлен 6-значный код подтверждения. Введите код.

<img src="/images/app-store/02-two-factor-authentication.png" alt="Двухфакторная аутентификация" style="max-width:100%;border-radius:8px;" />

### Шаг 3: Доверять этому браузеру

Появится запрос **"Trust this browser?"**. Нажмите **Trust**, чтобы в следующий раз не запрашивался код подтверждения.

<img src="/images/app-store/03-trust-this-browser.png" alt="Доверять этому браузеру" style="max-width:100%;border-radius:8px;" />

### Шаг 4: Перейдите в Users and Access

На главной странице App Store Connect нажмите раздел **Users and Access**.

## 3. Создание API ключа и получение Issuer ID

### Шаг 5: Перейдите на вкладку Integrations и скопируйте Issuer ID

Нажмите вкладку **Integrations** в верхнем меню. Убедитесь, что в левой панели выбран **App Store Connect API**. В верхней части страницы отображается **Issuer ID** — скопируйте его. Этот ID потребуется ввести в Replai.

<img src="/images/app-store/05-integrations-tab-page-and-take-issuer-id.png" alt="Вкладка Integrations и Issuer ID" style="max-width:100%;border-radius:8px;" />

### Шаг 6: Нажмите Generate API Key

Нажмите кнопку **"+"** или **Generate API Key**. В появившемся окне:

- Введите имя ключа в поле **Name** (например, `Replai`)
- Выберите роль в разделе **Access** (например, **Developer**)
- Нажмите **Generate**

<img src="/images/app-store/06-generate-api-key.png" alt="Создание API ключа" style="max-width:100%;border-radius:8px;" />

### Шаг 7: Скопируйте Key ID и скачайте файл .p8

После создания ключа он появится в списке **Active**:

- Скопируйте значение из столбца **Key ID**
- Нажмите кнопку **Download** для загрузки файла `.p8`

> **Важно:** Файл `.p8` можно скачать только **один раз**! Сохраните его в безопасном месте.

<img src="/images/app-store/07-take-key-id-and-p8-file.png" alt="Key ID и загрузка файла .p8" style="max-width:100%;border-radius:8px;" />

## 4. Получение App ID

### Шаг 8: Перейдите в раздел Apps

На главной странице App Store Connect нажмите **Apps** в верхнем меню. Выберите нужное приложение.

<img src="/images/app-store/08-take-app-id.png" alt="Выбор приложения" style="max-width:100%;border-radius:8px;" />

### Шаг 9: Скопируйте App ID из URL

После открытия страницы приложения посмотрите на адресную строку браузера. В URL отображается номер **App ID** (например, `https://appstoreconnect.apple.com/apps/1234567890/...`). Скопируйте этот номер.

<img src="/images/app-store/09-take-app-id.png" alt="Получение App ID из URL" style="max-width:100%;border-radius:8px;" />

## 5. Подключение к Replai

Перейдите на [replai.uz](https://replai.uz) и войдите в свой аккаунт. Перейдите в раздел **Accounts** на левой панели, нажмите **+ Add account** и выберите **App Store**. Введите следующие данные:

| Поле | Описание | Где найти |
|------|----------|-----------|
| **Issuer ID** | Идентификатор владельца API ключа | Шаг 5: Верхняя часть страницы Integrations |
| **Key ID** | ID номер API ключа | Шаг 7: Столбец Key ID в списке Active |
| **Private Key (.p8)** | Файл приватного ключа | Шаг 7: Загружен через кнопку Download |
| **App ID** | Числовой идентификатор приложения | Шаг 9: Из URL в адресной строке браузера |

После ввода данных нажмите **Connect**.

## Что происходит дальше

После подключения Replai автоматически запускает следующие процессы:

1. **Синхронизация отзывов** — отзывы из App Store появляются в панели Replai.
2. **Мониторинг отзывов** — система регулярно проверяет новые отзывы.
3. **Система ИИ-предложений** — Replai генерирует предложения ответов на основе контекста отзыва.

## Настройки

Настройте поведение аккаунта в **Настройках аккаунта**:

### Настройки автоответа
* **Включить автоответ**: Автоматическая публикация ИИ-ответов, соответствующих вашему порогу уверенности.
* **Проверка перед публикацией**: Удержание ответов для ручного утверждения перед публикацией.

### Фильтры отзывов
* **Фильтр отзывов**: Синхронизация всех отзывов или только без ответов.

## Устранение неполадок

### «API ключ не найден»
**Проблема:** Replai не принимает API ключ.
**Решение:** Повторно загрузите файл `.p8`. Убедитесь, что Issuer ID и Key ID скопированы правильно.

### «Доступ запрещён (Forbidden)»
**Проблема:** API ключ не имеет достаточных прав.
**Решение:** Убедитесь, что роль API ключа указана правильно. Измените роль в App Store Connect → Users and Access → Integrations.

### «Отзывы не отображаются»
**Проблема:** Отзывы не появляются в панели.
**Решение:** Убедитесь, что ваше приложение опубликовано в App Store. Через API видны только отзывы опубликованных приложений.

### «Потерян файл .p8»
**Проблема:** Загруженный файл приватного ключа потерян.
**Решение:** Отзовите (Revoke) старый ключ и создайте новый API ключ, затем снова загрузите файл `.p8`.

## Конфиденциальность и безопасность

* **Безопасное соединение**: API ключ хранится в зашифрованном виде.
* **Ограниченный доступ**: Replai получает доступ только к отзывам для чтения и ответов. Он не может получить доступ к другим данным вашего приложения.
* **Возможность отзыва**: Вы можете отозвать (Revoke) API ключ из App Store Connect в любое время.

## Часто задаваемые вопросы

**В: Можно ли подключить несколько приложений?**
О: Да! Для каждого приложения вводится отдельный App ID. API ключ работает для всех приложений.

**В: API ключ бесплатный?**
О: Да, создание API ключа бесплатно. Однако требуется членство в Apple Developer Program ($99/год).

**В: Я потерял файл .p8, что делать?**
О: Отзовите старый ключ и создайте новый. Каждый ключ можно скачать только один раз.

**В: Какую роль нужно выбрать?**
О: Для чтения отзывов и ответов на них достаточно роли **Developer** или **App Manager**.

## Ограничения

- **Квота API**: API Apple имеет почасовые лимиты запросов.
- **Только опубликованные приложения**: Видны только отзывы приложений, опубликованных в App Store.
- **Длина ответа**: Максимальная длина ответа на отзыв в App Store составляет 5 970 символов.
- **Однократная загрузка**: Файл ключа `.p8` можно скачать только один раз.
