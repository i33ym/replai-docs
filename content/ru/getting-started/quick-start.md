## Обзор

Это руководство проведёт вас через шаги для получения первого ответа ИИ в Replai. Процесс занимает менее 5 минут.

---

## 1. Создание аккаунта

1. Перейдите на [replai.uz](https://replai.uz)
2. Нажмите кнопку **Регистрация**
3. Введите имя, email и пароль (подтвердите пароль дважды) или быстро зарегистрируйтесь через **Google/Facebook**
4. Введите код подтверждения, отправленный на вашу почту, на платформе
5. Войдите с помощью email и пароля

> Если у вас уже есть аккаунт, просто войдите в систему.

---

## 2. Подключение платформы

После входа подключите свой первый аккаунт социальной сети:

1. Перейдите в раздел **Accounts** на левой панели
2. Нажмите кнопку **+ Add account**
3. Выберите платформу (напр., **Instagram**, **Facebook**, **YouTube** и др.)
4. Следуйте инструкциям для авторизации доступа

Подробные руководства для каждой платформы:

## 3. Знакомство с панелью управления

После подключения платформы панель управления Replai состоит из следующих разделов:

### Основная панель
- **Комментарии/Отзывы** — комментарии со всех платформ в одном месте
- **Предложения ИИ** — сгенерированные ИИ варианты ответов для каждого комментария
- **Статистика** — количество отвеченных, ожидающих и пропущенных комментариев

### Левая панель
- **Dashboard** — обзор
- **Accounts** — подключённые аккаунты
- **Настройки** — настройки платформы

---

## 4. Получите первый ответ ИИ

1. Просмотрите новые комментарии на **Dashboard**
2. Нажмите на комментарий
3. Replai автоматически покажет предложение ответа ИИ
4. Проверьте ответ:
   - **Опубликовать** — опубликовать ответ напрямую
   - **Редактировать** — изменить ответ перед публикацией
   - **Отклонить** — запросить другое предложение
5. После публикации ответ автоматически появится на соответствующей платформе

---

## 5. Настройка правил ответов (необязательно)

Вы можете настроить Replai под свои нужды:

### Настройки тона ИИ
В **Настройки → ИИ → Тон** выберите стиль ответов:
- **Официальный** — для бизнес и корпоративных аккаунтов
- **Дружелюбный** — для брендов и личных аккаунтов
- **Нейтральный** — универсальный стиль

### Автоответ
В **Настройки → ИИ → Автоответ**:
- Автоматическая публикация ответов ИИ или работа в режиме проверки
- Установка порога уверенности (напр., автопубликация при уровне выше 85%)

### Фильтры комментариев
В **Настройки → Фильтры**:
- Синхронизация всех комментариев или только неотвеченных
- Фильтрация по определённым ключевым словам
