## Доступ к Replai

Replai — это облачная (cloud) платформа. Установка не требуется — вы можете использовать её через браузер или мобильное приложение.

### Веб-версия

Перейдите на [replai.uz](https://replai.uz) в браузере и войдите в систему или создайте новый аккаунт.

**Поддерживаемые браузеры:**
- Google Chrome (рекомендуется)
- Safari
- Firefox
- Microsoft Edge

### Мобильное приложение

Скачайте мобильное приложение Replai:

- **iOS**: [Скачать из App Store](https://apps.apple.com/app/replai)
- **Android**: [Скачать из Play Store](https://play.google.com/store/apps/details?id=uz.replai)

## Создание аккаунта

### Шаг 1: Регистрация

Перейдите на [replai.uz](https://replai.uz) и нажмите кнопку **Регистрация**.

### Шаг 2: Введите данные

Введите следующие данные:

- **Имя и фамилия**
- **Адрес электронной почты**
- **Пароль** (минимум 8 символов)

Или быстро зарегистрируйтесь через социальные сети:
- Продолжить через **Google**
- Продолжить через **Facebook**

### Шаг 3: Подтверждение email

На вашу почту будет отправлено письмо с подтверждением. Перейдите по ссылке в письме для активации аккаунта.

### Шаг 4: Вход в систему

После подтверждения войдите с помощью email и пароля.

## Самостоятельное развёртывание (Self-hosting)

Если вы хотите запустить Replai на собственном сервере, необходимо выполнить следующие требования.

### Системные требования

- Python 3.11+
- PostgreSQL 15+
- NATS server
- Redis (необязательно, для кеширования)

### Установка через Docker

```bash
docker pull replai/replai:latest
docker compose up -d
```

### Установка из исходного кода

```bash
git clone https://github.com/i33ym/replai.git
cd replai
uv sync
```

> Подробнее о self-hosting смотрите на странице [GitHub](https://github.com/i33ym/replai).
