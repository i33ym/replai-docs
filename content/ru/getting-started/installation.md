## Доступ к Gapex

Gapex — это облачная (cloud) платформа. Установка не требуется — вы можете использовать её через браузер или мобильное приложение.

### Веб-версия

Перейдите на [gapex.ai](https://gapex.ai) в браузере и войдите в систему или создайте новый аккаунт.

**Поддерживаемые браузеры:**
- Google Chrome (рекомендуется)
- Safari
- Firefox
- Microsoft Edge

---

## Создание аккаунта

### Шаг 1: Регистрация

Перейдите на [gapex.ai](https://gapex.ai) и нажмите кнопку **Регистрация**.

### Шаг 2: Введите данные

Введите следующие данные:

- **Имя**
- **Адрес электронной почты**
- **Пароль** (минимум 8 символов)
- **Подтверждение пароля** (введите пароль повторно)

Или быстро зарегистрируйтесь через социальные сети:
- Продолжить через **Google**
- Продолжить через **Facebook**

### Шаг 3: Подтверждение email

На вашу почту будет отправлен код подтверждения. Введите этот код на платформе для активации аккаунта.

### Шаг 4: Вход в систему

После подтверждения войдите с помощью email и пароля.

## Самостоятельное развёртывание (Self-hosting)

Если вы хотите запустить Gapex на собственном сервере, необходимо выполнить следующие требования.

### Системные требования

- Python 3.11+
- PostgreSQL 15+
- NATS server
- Redis (необязательно, для кеширования)

### Установка через Docker

```bash
docker pull gapex/gapex:latest
docker compose up -d
```

### Установка из исходного кода

```bash
git clone https://github.com/i33ym/gapex.git
cd gapex
uv sync
```

> Подробнее о self-hosting смотрите на странице [GitHub](https://github.com/i33ym/gapex).
