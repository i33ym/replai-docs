## Общие настройки

После входа в систему перейдите в раздел **Настройки** на левой панели. Здесь вы можете управлять основным поведением платформы.

---

## Настройки профиля

В **Настройки → Профиль** измените следующее:

| Настройка | Описание |
|-----------|----------|
| **Имя и фамилия** | Ваше имя, отображаемое на панели управления |
| **Email** | Электронная почта, привязанная к аккаунту |
| **Пароль** | Изменение пароля аккаунта |
| **Язык** | Язык интерфейса (O'zbekcha, English, Русский) |

---

## Уведомления

В **Настройки → Уведомления** настройте следующее:

- **Уведомления о новых комментариях/отзывах**: Получайте уведомления при поступлении нового комментария
- **Готовность ответа ИИ**: Получайте уведомления, когда ИИ подготовит предложение ответа
- **Еженедельный отчёт**: Получайте еженедельную статистику по электронной почте
- **Push-уведомления**: Включение/отключение push-уведомлений в мобильном приложении

---

## Настройки ответов ИИ

В **Настройки → ИИ** настройте поведение ИИ:

### Стиль ответов

| Настройка | Описание |
|-----------|----------|
| **Тон** | Официальный, дружелюбный или нейтральный стиль ответов |
| **Длина** | Короткие, средние или подробные ответы |
| **Язык** | Язык ответов ИИ |

### Автоответ

| Настройка | Описание |
|-----------|----------|
| **Автоответ** | Автоматическая публикация ответов ИИ (вкл/выкл) |
| **Порог уверенности** | Минимальный уровень уверенности для автопубликации (напр., 85%) |
| **Режим проверки** | Ручное утверждение ответов перед публикацией |

> **Рекомендация:** Начните с включённого **Режима проверки**. После ознакомления с ответами ИИ переключитесь на автоматический режим при необходимости.

---

## Интеграции аккаунтов

В **Настройки → Интеграции** управляйте подключёнными платформами:

- Просмотр списка подключённых аккаунтов
- Добавление новой платформы
- Отключение существующей платформы
- Установка индивидуальных настроек для каждой платформы

Поддерживаемые платформы:
- Instagram
- Facebook
- YouTube
- Telegram
- Play Store
- App Store

Подробные руководства по подключению каждой платформы можно найти в разделе [Платформы](../../platforms/).

## Конфигурация для self-hosting

Если вы запускаете Replai на собственном сервере, создайте файл `.env` в корневой папке проекта:

```env
DATABASE_URL=postgresql://user:pass@localhost:5432/replai
NATS_URL=nats://localhost:4222
ANTHROPIC_API_KEY=sk-ant-...
REDIS_URL=redis://localhost:6379
```

| Переменная | Описание |
|------------|----------|
| `DATABASE_URL` | Подключение к базе данных PostgreSQL |
| `NATS_URL` | Адрес сервера обмена сообщениями NATS |
| `ANTHROPIC_API_KEY` | API-ключ Anthropic для ответов ИИ |
| `REDIS_URL` | Сервер кеширования Redis (необязательно) |
